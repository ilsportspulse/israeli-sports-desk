## Operating rule

The newsroom cycle and company-build roadmap run in parallel. After the mandatory discovery and integrity gate, every recurring run must complete or materially advance one safe local roadmap item. If urgent newsroom work consumes the full run, the cycle report must say so and the next run resumes from the first executable item below.

Every completed item needs evidence: a working file, tested code, a rendered asset, a verified research record or a documented decision. Production deployment, purchases, domain registration, account creation and external messages remain owner-approval gates.
